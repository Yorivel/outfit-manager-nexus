# Outfit Manager - English. Every line the mod shows, as "key = text".
# Translating: copy this file to your language's code (de.txt, fr.txt, ... see README) and change the text after "=".
# Keep the {words} in braces: the mod fills them in (an outfit's name, a number, ...); move them where your language needs them.
# {sp} is a space (for the separators).
# Lines left out show in English. "<br/>" is a line break.
# Your own changes: put them in <code>.custom.txt (the same format, only the lines you change). Mod updates never touch
# that file, and its lines win over the shipped ones.
# Plurals: a key ending in .one / .few / .many / .other is chosen by the number (few/many: Polish, Russian, Arabic ...;
# a missing form falls back to .other).
